Monoprice Monolith HTP-1

Control4 driver for the HTP-1 AV processor.

Driver 110 · Control4 OS 3.x · HTP-1 firmware 1.13.x or 2.1.x

What it does

  • Power on, standby and sleep
  • Input selection across all 20 inputs
  • Volume, hold-to-ramp, and mute
  • Loudness from the room's own control
  • Listening mode selection
  • Dirac Live on and off, and filter selection
  • Night mode, dialog and bass enhancement, lip sync
  • Runs macros stored on the unit
  • Status and events for programming
  • Reconnects on its own

Changes made on the front panel, the unit's remote or its web page appear in Control4 without being asked for.

Installing

  1. Add the driver to the room.
  2. On the Connections tab, enter the unit's IP address. Use a fixed address or a DHCP reservation.
  3. Bind your sources to the HDMI inputs, the display to an HDMI output, and the amplifiers to the audio output.
  4. Bind the room to the Room Selection end-point.

The driver claims no room end-points on its own. Every binding is yours to make.

Connection Status showing Connected, with the version and serial fields filled in, confirms it is working. If it stays Not connected, check the IP address.

Updating

  1. Copy the new Monolith.HTP1.c4z over the old one in your Drivers folder.
  2. Driver › Add or Update Driver or Agent…, and select the file.
The device icon only changes if you remove and re-add the device. Control4 sets a device's icon when the device is added, and does not update it afterwards.

Macro The unit's stored macros Chooses which macro the Run Selected Macro action runs. Only slots holding something appear. Selecting one does not run it.
The driver never fully shuts the unit down. The unit's own SHUTDOWN turns its network off with it, and nothing on the network can wake it again. Powering the room off puts the unit to sleep instead, which keeps it reachable.
Macros are run, not created. Macros are recorded on the unit itself. This driver lists them and runs them; it cannot add, edit, rename or delete one. Only replace steps are replayed. A macro containing other kinds of step runs in part, and the driver reports how many steps it skipped in the Lua tab.

Inputs

All 20 inputs are available: 8 HDMI, 2 analog, 2 coax, 2 optical, AES, USB, Bluetooth, Roon and two network inputs. Print Input Labels lists what the unit calls each one.

Rename connections yourself. A driver cannot rename its own Control4 connections. Use Print Input Labels to see the unit's names, then rename the connections in Composer to match.

Known limitations

  • Loudness is one-way. The room's Loudness control sets it, but a change made on the unit does not move the button. The LOUDNESS variable stays correct.
  • Input names are not copied into Control4 connection names.
  • Macros cannot be created or edited from Control4.

Troubleshooting

SymptomCheck
Connection Status stays Not connected The IP address, and that the unit is powered and on the network.
Room volume buttons do nothing The room is bound to the Room Selection end-point.
Volume moves too far, or not far enough Maximum Volume, which rescales the room's volume range.
The system turns off with the room Set Power Off Action to Do Nothing.
The icon did not change after an update Remove the device and add it again.
Reporting a problem Set Debug Mode to On for 15 Minutes, reproduce it, then run Print Driver State and copy the Lua tab.
